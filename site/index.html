Emphasis rules

How Caption Cues works

Uses caption text already on the page

Caption Cues reads exposed caption text. It does not capture audio, download video, or create a transcript.

  1. 01

    Turn captions on

    Start the captions offered by your video player.

  2. 02

    Choose your cues

    Mark names, speaker labels, sound cues, or a saved word.

  3. 03

    Replay the last line

    Press Alt + R to replay a timed cue or reshow visible caption text.

When a player is unsupportedCaption Cues leaves hidden caption pixels and closed components unchanged. It tells you when exposed caption text is unavailable.

Installation and compatibility

Install and use the extension

How do I install the download?

Unzip it. Open chrome://extensions. Turn on Developer mode, choose “Load unpacked,” then select the unzipped folder.

Does it send my captions anywhere?

No. Caption text and settings stay in your browser. Caption Cues has no analytics or remote runtime scripts.

Which videos work?

It supports standard browser caption tracks and selected caption text shown on the page.

Which videos do not work?

It cannot change captions hidden in video pixels or inaccessible closed components.
